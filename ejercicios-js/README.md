# Ejercicios de JavaScript en HTML

Copia de los ejercicios, cada uno en su propia carpeta con su `index.html`.

- `ex-6.2-6.4`: funciones, objetos y objetos estándar (String, Array, Date, Math). La salida se ve en la consola del navegador (F12).
